# Font licenses

The web fonts in this directory are **self-hosted** — the site makes no
third-party font requests. Each was taken from its upstream project and
re-encoded to `woff2`, subset to Latin + Latin Extended (enough for Turkish
and the symbols the site uses). Subsetting and format conversion are the only
modifications. Upstream links point to the project source.

If a face is ever missing, the browser falls back to the system monospace
stack declared in `css/base.css`.
